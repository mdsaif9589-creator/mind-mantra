# MIND MANTRA - Audio Assets Requirement

This file outlines the required audio assets for the MIND MANTRA application. The system expects these files to be present locally in the `public/audio/` directory.

## Required Structure & Files

Place your `.mp3` files in the following exact locations. Ensure filenames are entirely lowercase, use hyphens instead of spaces, and do not contain special characters.

### NATURE
- `/audio/nature/light-rain.mp3`
- `/audio/nature/forest.mp3`
- `/audio/nature/water-river.mp3`
- `/audio/nature/wind.mp3`

### LIFE
- `/audio/life/morning-birds.mp3`
- `/audio/life/night-crickets.mp3`
- `/audio/life/campfire.mp3`
- `/audio/life/long-rain.mp3`

### AMBIENCE
- `/audio/ambience/meditation.mp3`
- `/audio/ambience/atmospheric.mp3`

### MIND
- `/audio/mind/calm-meditation.mp3`
- `/audio/mind/deep-focus.mp3`
- `/audio/mind/sleep.mp3`
- `/audio/mind/relaxation.mp3`
- `/audio/mind/breathing-mindfulness.mp3`

## Note
- If a file is missing, the application will display "Audio file not found" in the UI.
- Replace any placeholders with actual production-ready, correctly licensed audio files.
